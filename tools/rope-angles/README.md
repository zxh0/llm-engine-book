# RoPE旋转角度

把RoPE每个位置、每个平面转了多少画出来，再用两个可以拖动的向量演示：旋转之后的点积，
只和两个位置的差有关。默认是SmolLM2的参数。配合第七章「旋转位置编码」一节看。

打开 `index.html` 即可，没有构建步骤，也没有任何依赖。

## 算的是什么

```
θ_i = base^(−2(i−1)/d)       i = 1 … d/2
第 m 个位置的第 i 个平面转 m·θ_i 弧度
```

平面 i 从1开始编号，和正文、RoFormer论文一致；代码里从0开始，第 i 个平面在代码里是第 i−1 个。

## 上半：每个平面转了多少

三种视图：

- **转角（按平面）**：行是位置 m，列是平面 i，颜色是转角对一圈取余，用色环表示，色环转一圈，
  向量也正好转一圈。左边的平面颜色变得快，右边几乎不变。
- **cos表 / sin表（按维度）**：就是 `code/book/ch07/model.py` 里 `rope_table()` 算出来的那两张表，
  每列是一维。half-split下左右两半一模一样，这正是 `torch.cat((angles, angles))` 那一行做的事。
  悬停时，同一个平面的另一维会用虚线框出来。

鼠标放到任意一格上，下方显示：位置 m、平面 i、这个平面用哪两维（随配对方式变化）、θ_i、
转角（弧度和度数）、转了几圈、cos 和 sin 的值、转一圈要几个位置。转一圈要的位置数比8192
（SmolLM2的 `max_position_embeddings`）还长时，会标出来：这样的平面在整个上下文里都转不满一圈。
右边的表盘画出这个平面里一个向量转之前（虚线）和转之后（实线）的样子。

## 下半：为什么只和相对位置有关

用固定种子生成一组 q 和 k（d维），q 放在第 m 个位置，k 放在第 n 个位置，各自按位置旋转，
再算点积。四个滑块：

| 滑块 | 作用 |
|------|------|
| 平面 i | 表盘画哪个平面 |
| q 的位置 m | |
| k 的位置 n | |
| 整体平移 s | m 和 n 同时加上 s |

拖 s 时，两根向量一起转，夹角不变，「这个平面的点积」和「整个头的点积」都不变；
只改 n，点积才会变。整个头的点积是 d/2 个平面各自的点积之和，用的是真正的配对方式，
不是只算一个平面。

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 每个头的维度 d | 64 | SmolLM2的 `head_dim`，偶数 |
| 位置数 T | 100 | 最多8192 |
| 底数 base | 100000 | SmolLM2的 `rope_theta`；RoFormer论文是10000 |
| 配对方式 | half-split | SmolLM2的 `rope_interleaved: false`；RoFormer论文是相邻配对 |

预设：SmolLM2、RoFormer论文、SmolLM2全上下文（T=8192）、正文小例子（d=8、T=4）。
参数会同步到地址栏：

```
index.html?d=64&n=8192&base=100000&pair=half
```
