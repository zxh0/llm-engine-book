# 正弦位置编码热力图

把《Attention Is All You Need》3.5节的位置编码表画成一张热力图：行是位置，列是维度，
颜色是编码的值。鼠标放到任意一格上，会显示这一格的位置、组号 i、用的是 sin 还是 cos，
以及完整的计算过程。

打开 `index.html` 即可，没有构建步骤，也没有任何依赖。配合第七章「正弦位置编码」一节看。

## 算的是什么

```
PE(pos, 2i)   = sin(pos / base^(2i/d))
PE(pos, 2i+1) = cos(pos / base^(2i/d))
```

位置和维度都从0开始编号，和论文一致。第 2i 列和第 2i+1 列是一组，共用同一个角度，
一个取 sin、一个取 cos。悬停时，同组的另一列会用虚线框出来。

信息栏里的「这一组转一圈要几个位置」就是波长 2π·base^(2i/d)：最左边那组是 2π ≈ 6.28，
越往右越长，底数10000、d=512时，最右边那组要六万多个位置才转一圈。

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 维度 d | 512 | 论文的 `d_model`。必须是偶数，奇数会自动加1 |
| 位置数 T | 100 | 画多少行 |
| 底数 base | 10000 | 论文的取值 |

三个预设：论文的 d=512；d=64，条纹更清楚；d=8、T=4，就是正文里那张小表，
数值和 `code/book/ch07/sinpe.py` 打印的一样。

参数会同步到地址栏，可以直接用链接定位：

```
index.html?d=64&n=100&base=10000
```

## 实现

先在一张 d×T 的小画布上逐格填色，再关掉插值放大到绘图区，所以每一格的边界都是清楚的。
d=512 时一列不到两个像素，在普通屏幕上会出现一点莫尔纹，这是像素不够，不是算错了；
想看清楚可以把 d 调小。配色是 matplotlib 的 `coolwarm`，均匀取了17个点，中间线性插值。
